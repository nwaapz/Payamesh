# وب‌سایت پایامش (Payamesh Website)

وب‌سایت تبلیغاتی استاتیک شرکت پایامش — فارسی، راست‌به‌چپ، با تم فضایی.

## ساختار

```
Payamesh/
  index.html      صفحه اصلی (تک‌صفحه‌ای)
  css/style.css   استایل‌ها (تم فضایی، کارت‌های شیشه‌ای، ریسپانسیو)
  js/main.js      انیمیشن ستاره‌ها، افکت اسکرول، منوی موبایل
```

## انتشار (Deploy)

سایت کاملاً استاتیک است و هیچ بک‌اند یا مرحله build ندارد.
کافی است کل پوشه `Payamesh/` را روی هر هاستی (آپاچی، Nginx، هاست اشتراکی، GitHub Pages و...) کپی کنید.

برای مشاهده محلی، فایل `index.html` را مستقیم در مرورگر باز کنید یا:

```
cd Payamesh
python -m http.server 8080
```

## فونت

فونت «وزیرمتن» از CDN (jsdelivr) بارگذاری می‌شود و در صورت در دسترس نبودن، فونت سیستم جایگزین می‌شود.
برای هاست کاملاً آفلاین، فایل‌های فونت را دانلود و مسیر `<link>` در `index.html` را محلی کنید.
